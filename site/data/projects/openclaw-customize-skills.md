## README

OpenClaw 自定义 Skill 库。三个生产级 Skill：

- **moltbook-daily** — 日报生成 + 抖音风文案 + 定时邮件推送
- **wordpress-blog-writer** — 主题 → 大纲 → HTML → GitHub 备份 → WordPress 发布全链路
- **story-writer** — 自动选题 + 严格字数大纲 + 章节生成

> 详情待与 Maxwell 讨论后补充：每个 Skill 的设计取舍、cron 调度策略、生产实战中遇到的坑。
