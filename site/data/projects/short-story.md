## README

为「番茄小说」平台创作商业级短篇故事的 **Claude Code 工作流 + Playwright 自动发布**。每篇 7000-10000 字 TXT 纯文本，每日配额 20 篇覆盖 9 个品类（追妻火葬场 / 真假千金 / 重生复仇 / 家庭伦理 / 豪门总裁 / 悬疑惊悚 / 年代文 / 现言甜宠 / 差异化）。**截至 5/6 累计 106 篇 / 89.2 万字（约 4/28-5/6）**，已发布 3 篇（#79-#81）。

**写作方法论**（`prompts/writing-methodology.md` 完整版）：黄金 8 步法 + 5 种情绪曲线轮换 + 莱昂纳德十大法则（不写天气 / 只用"说" / 全篇感叹号 ≤ 5 / 不写简历式外貌）+ 3 秒原则（第一句必有冲突）+ 配角自主行动 + 中段二次冲突 + 伏笔前 1/3 埋结尾收。

**初稿字数铁律**（5/4 三轮实战验证）：Claude 自然写作风格偏克制简洁，初稿稳定落 4500-6700 字。**第一稿目标 9000-10000 字**，每篇 2-4 轮扩写（每轮 +200-800 字）。**最有效扩写手段（按效果排序）**：① 补时间跨度后缀（+300-600）② 补第三方视角（+200-500）③ 补职业细节（+200-400）④ 补家人线（+200-400）⑤ 补关键道具象征。

**Playwright 自动发布全流程**（`memory/project-publishing-pipeline.md` 完整版）：Python 剥元信息 + `pbcopy` → Playwright MCP 操作番茄发布页（标题 nativeSetter / ProseMirror 粘贴 / 智能分章 / AI=是 / 主分类 / 试读 36% 走 ProseMirror transaction / 协议弹窗 / 封面 1 号）→「下一步」×2 →「继续发布」→「确定」→ 文件加【已发布】后缀。**用户已永久授权"下一步直接点不问"**。

风控：番茄对作家发布频率有监控，建议每天最多发 2-3 篇。

## NOTES

- **题材去重新模板**（5/6 验证）— 同一题材连续写多篇容易陷入相似结构（如重生复仇连续两篇都是"前世吊销资格 → 重生提前布局"）。**新模板探索**：真假千金从「等家人来认」→「主角已经独立」（MIT 博士、评书演员）；重生复仇从「撕逼对峙」→「专业能力反击」（文物鉴定、法医）；悬疑题材「夜校六条规则」把鬼怪与温情结合（鬼怪不是恐怖元素而是情感载体）。**单题材连写 3+ 篇必须刻意换模板**，否则平台审核也会判同质化。

- **情感驱动型 vs 情节驱动型的字数规律**（5/4 累计验证）— 追妻火葬场 / 豪门总裁等情感驱动型题材天然 9000+，因为对话密集、情绪对峙多；年代文 / 悬疑惊悚 / 现言甜宠等情节驱动型天然 5000-7000，需刻意加 30%+ 对话占比 + 至少 2 个额外独立场景。**新题材警告**：古风世情 / 民国旧影 / 青春虐恋 / 虐心婚恋 4 类初稿全部 < 6000 字（古风最短 ~2700），需完全不同的词汇体系。

- **Playwright MCP 操作番茄编辑器的工程坑**（5/7 修正）— 番茄发布页用 React + ProseMirror，几个**反直觉操作**：① textarea 直接 `.value =` 不会触发 React onChange，必须 `Object.getOwnPropertyDescriptor(HTMLTextAreaElement.prototype, 'value').set.call(el, val)` + dispatch input event；② ProseMirror view 实例不在 DOM 上找，要遍历 `window` 顶层属性找有 `.state.doc.dispatch` 且 `.dom === pm` 的对象；③ 试读比例直接走 ProseMirror transaction（找 payNode leaf node + tr.delete + tr.insert 移动）比拖拽 UI 快 10 倍且不出错；④ 协议复选框第一次 click 必弹"我已阅读并同意"对话框，不是直接勾选。

- **黄金 8 步法的"中点反转"是核心**（writing-methodology 实战）— 短篇故事 7000-10000 字 8 步结构：① 钩子开场（3 秒原则）② 设定铺陈（不超过 500 字）③ 第一冲突起 ④ **中点反转**（真假胜负交替）⑤ 二次冲突（反派主动行动制造更大障碍）⑥ 危机高潮（用对话和行为推进，禁止旁白解密）⑦ 真相揭露（伏笔回收）⑧ 首尾呼应（呼应导语意象/物件/台词）。**没有中点反转的短篇是死气沉沉的流水账**。

- **扩写不是注水**（5/4 教训）— 每处扩写必须满足至少一项：推动情节 / 塑造人物 / 增加冲突 / 回收伏笔。**纯描写性扩写一律删除**。早期版本为达字数加大段心理描写 / 环境描写，反而拉低节奏（莱昂纳德"删掉读者会跳过的部分"），后改为按"5 大有效手段"排序补内容。
