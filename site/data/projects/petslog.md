## README

宠物健康管理系统。uni-app 双端（微信小程序 + H5）+ Vue 3 + uniCloud + ECharts + Notion API 集成。功能：用药记录 / 健康报告 / 提醒推送 / 离线模式 / 语音输入。

**双工具实现对比**：同一份 PRD 用 [Cursor](https://github.com/iyuenan3/Cursor-PetsLog) 和 [OpenClaw](https://github.com/iyuenan3/OpenClaw-PetsLog) 各做一遍，对比 Vibe Coding 全栈交付下两种工具的差异（速度 / 准确性 / 调试体验 / 上下文管理）。这个项目本身是"AI 落地实战"的对照实验。

> 详情待与 Maxwell 讨论后补充：双工具对比的关键发现、踩坑、Cursor vs OpenClaw 各自的强项与短板。
